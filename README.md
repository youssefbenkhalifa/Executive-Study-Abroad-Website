# Executive Study Abroad Website

This is a fully responsive and interactive website for **Executive Study Abroad**, an organization that assists Tunisian students in applying to universities in **Australia, the UK, and Canada**.

## Features

- **Navigation & UI**: User-friendly interface with easy navigation.
- **Hero Section**: Engaging welcome message with a strong call to action.
- **Featured Universities**: Showcases partner universities.
- **Services Section**: Highlights offerings such as career counseling, visa assistance, and accommodation support.
- **News & Events**: Updates on upcoming university events and international education insights.
- **Study Destinations**: Information on study opportunities in Australia, Canada, and the UK.
- **Testimonials**: Real experiences from students who have benefited from the services.
- **Social Media Integration**: Links to social media pages for engagement.

## Technologies Used

- **HTML, CSS, JavaScript**: Front-end development.
- **Bootstrap**: Responsive design.
- **JavaScript Interactivity**: Enhancements like slideshows and dynamic content.

## Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/youssefbenkhalifa/Executive-Study-Abroad-Website.git
   ```
2. Navigate to the project folder:
   ```sh
   cd Executive-Study-Abroad-Website
   ```
3. Open `index.html` in a browser.
